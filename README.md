# 🚘 AZULCar - Frontend

Une application web moderne de **location de voitures**, offrant des interfaces distinctes pour les **clients** et les **administrateurs**, afin de gérer efficacement le processus de réservation, la flotte de véhicules et le suivi des locations.

---

## 🚀 Fonctionnalités principales

- 🧭 **Interface client fluide** : navigation, recherche et réservation de voitures.  
- 🗂️ **Espace administrateur** : gestion des voitures, clients, contrats et paiements.  
- 📅 **Système de réservation dynamique** avec gestion de la disponibilité.  
- 💳 **Paiement et facturation** simulés.  
- 🔐 **Authentification & autorisation sécurisées** (Spring Security / JWT).  
- 📊 **Tableau de bord admin** avec statistiques et indicateurs.  
- 📱 **Interface responsive** (MUI) pour tous les appareils.

## 🏁 Objectifs du projet

- Créer une **plateforme de location de voitures complète et sécurisée**.  
- Fournir une **expérience fluide** pour les clients (réservation rapide, gestion du profil).  
- Offrir aux administrateurs un **outil performant** de gestion de la flotte et des clients.  
- Appliquer les bonnes pratiques de développement **Spring Boot + React** en architecture moderne.
